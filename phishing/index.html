Phishing Email Analyzer

Paste the original source of a suspicious email and see where it really came from, whether it passed SPF, DKIM and DMARC, and which warning signs it shows.

Nothing is uploaded — the analysis runs in your browser
Where do I find the email source?
  • Gmail: open the email → ⋮ More → Show original → Copy to clipboard
  • Outlook (web): open the email → ⋯ → View → View message source
  • Seznam Email: open the email → ⋯ → Show source. Seznam shows only the headers — use the Headers + text tab and paste the email text into the second box.
  • Thunderbird: open the email → Ctrl + U
  • Apple Mail: View → Message → Raw Source
